## ✨ Features

* **Interactive Hero Background**: Dynamic video playback synchronized with real-time cursor movements (`mousemove` scrubbing).
* **Typewriter Typography**: Smooth animated introductory text using custom hooks and robust timing delays.
* **Responsive Navigation**: Seamless switching between desktop link bars and a mobile-optimized slide-over overlay.
* **Interactive Pills & CTAs**: Quick-action pills for pitching ideas, career applications, exploring operations, and copying contact info directly to the clipboard.
* **Modern Tooling**: Fully typed with TypeScript and optimized with Vite for ultra-fast bundling and execution.
